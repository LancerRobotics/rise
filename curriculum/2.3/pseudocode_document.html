Pseudocode Document

Pseudocode (pronounced soo-dow-kowd): A way of writing out the steps of a program in plain, simple language (not real code).

  • “Pseudo” means fake, so it is essentially fake code
  • Its purpose is to give an outline of the steps needed for the program, which makes actually writing the program easier.
  • It can be written in plain english, but should follow a computer-like format, being very logical

Why is it important?

  • Imagine you need to write a very long and difficult program. If you jump straight into programming, you need to worry about how the blocks work, the formatting, and many little details. This can make you forget the bigger picture (what needs to happen, and in what order), especially in longer projects.
  • Pseudocode breaks up the big steps with the little details. You first make an outline, and then you just worry about the details, which can make the project much more manageable and organized.

Example:

Task: Make the robot go in a square of side length 200 mm.

Pseudocode:

Go forward 200 mm.
Turn left 90 degrees.
Go forward 200 mm.
Turn left 90 degrees.
Go forward 200 mm.
Turn left 90 degrees.
Go forward 200 mm.
Turn left 90 degrees.

This traces out a square, and leaves the robot pointing in the same direction in the same starting place after running. However, notice how we just did the same thing 4 times. We have room to improve.

Improved Pseudocode:

Repeat 4 times:
  Go forward 200 mm.
  Turn left 90 degrees.

This does the exact same thing, but is much shorter. Optimizations such as these should be done during pseudocode, not when actually writing the program.
