Lesson 17: Extra Challenge

Lesson Objectives

  • Have the students increase the complexity of their maze solving algorithm by incorporating sensors to navigate a random maze.

Materials Needed

  • Computers (ideally 1 per group)
  • Basebots
  • VEXcode IQ website
  • A randomly generated maze (created with white tape), preferably on a dark surface in order to make it easier to code the sensors. There should be colored tape (blue/red/green) marking the end of the maze.

Lesson Procedure

1. Overview

  • In this lesson, students will start to try navigating a maze that is randomly generated by following white tape.
  • Students will learn how to incorporate sensors to achieve this goal.

2. Getting Started

  • Review your sensors. Ask the students which sensors they think could be helpful. This website describes the functions of the different sensors in case they forgot: https://kb.vex.com/hc/en-us/articles/14021137100308-Overview-of-VEX-IQ-2nd-gen-Sensors
  • Have students research different maze solving algorithms and ask them to share their findings with the class (make sure they find the algorithm LSRB - turn left if you can turn left, else if you can go straight, go straight, else if you can turn right, turn right, else turn around). It is further explained at this website if necessary: https://towardinfinity.medium.com/coding-a-line-follower-robot-using-lsrb-and-finding-the-shortest-path-d906ffec71d

3. Monitoring Progress

  • Students will primarily need to use a color sensor to navigate the maze, so have them mount it on their robot in a desirable position.
  • The color sensor will be able to detect whether the robot is straying off the white line, or if the robot is at the end of the maze (will see a different color).

4. Wrapping Up

  • Students should spend the rest of class developing pseudocode for their maze algorithm.

Assessment

  • Students were able to write the pseudocode for their maze algorithm.
  • Students were able to properly identify the correct sensor to use in order to navigate the maze.

Preparation for next class

Students should start thinking about how they will make sure the robot tracks the white line and detects when it reaches a dead end. If students finish their pseudocode early, they will be able to start coding next class.
