Lesson 23: Work Day

Objective(s)

  • Students will brainstorm ideas and strategies for the Block Stacking Challenge.

Materials Needed

  • Notebooks
  • Computers
  • Basebots
  • VEXcode IQ

Lesson Procedure

1. Overview

  • Students will brainstorm strategies for the game.
  • Students will break their project into manageable parts.
  • Students will use MyBlocks to make their code more organized.

2. Getting Started

  • Groups should brainstorm strategies together for the game and write their ideas in their notebooks.
  • Encourage students to think about which actions need to happen first, which actions can repeat, and which parts of the robot must be controlled separately.

3. Monitoring Progress

  • Groups should create a plan for the project and break it into manageable steps by outlining what they will do each day to finish in time.
  • As a class, discuss how groups will organize their code and keep the project on schedule.
  • Introduce MyBlocks as a way to separate repeated or important actions. Ask students to come up with ideas for useful MyBlocks.

4. Wrapping Up

  • Students can begin writing pseudocode for each of their MyBlocks if they have time.

Assessment

  • Students should have a timeline in their notebook for each of the remaining work days.
  • Students should have a strategy outlined in their notebook.

Preparation for next class

Next class will begin pseudocode, so each group should be comfortable with its strategy.
