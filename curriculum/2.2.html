Lesson 2: VEX IQ Blocks Overview

Lesson Objectives

  • Navigate the code website and learn how to move blocks around.
  • Learn how to download a program to the brain.
  • Run a simple program that drives their robot forward.

Lesson Overview

The purpose of this lesson is to introduce students to the VEXcode IQ Blocks programming environment. In addition, students will learn how to connect their robot’s Brain to the programming software and download their first program, reinforcing the connection between digital commands and mechanical systems.

Materials Needed

  • Computers (ideally 1 per group)
  • Basebots
  • VEXcode IQ website
  • Notebooks for each student

Lesson Procedure

Getting Started

  • Begin straight with the computers and tell the students to go to codeiq.vex.com. Simply have the students play around for a couple minutes by dragging the blocks around. Make sure they figured out how to:
    • Drag blocks from the left side to the right side where the actual program is.
    • Stack blocks under each other, starting with the “when started” block.
    • Delete blocks in the program by either dragging them back to the left side or right-clicking and then choosing delete “Delete Block”.
  • Have students follow this video to set up a Drivetrain.
    • Don’t worry about things like the track width, wheelbase, gear ratio, and things like that, just use the default values. However, students should select the correct ports on the brain that their motors are connected to. Also make sure to select Brain Inertial when it asks for device option.
    • If done correctly, a new set of blocks should show up on the left side of the screen.

Monitoring Progress

  • Have students drag over the block that says “drive forward for 200 mm” and connect it to the “when started” block, as shown below. Make sure you hear a snap when the blocks are connected.
  • Follow this video to learn how to download the program to the brain.
  • To run the program, use the arrow buttons to select their program, and then click the check button to run. The bot should go forward 200 mm.

Wrapping Up

  • Students should open up their notebooks and reflect on the lesson by answering these questions:
    • What went well today?
    • Which part was more challenging for you?
    • What do you want your robot to do next?
  • End with a full class discussion to share their answers.

Assessment

  • Students can navigate the website and identify key features of it
  • Students can download a program from the computer to the brain
  • Students understand the connection between computer software and mechanical systems

Preparation for next class

The next class will be about a new concept called pseudocode. Robots and individual computers will not be necessary for the next lesson, so make sure they are all powered down and stored properly.
