Lesson 27: Work Day

Objective(s)

  • Students will continue writing and testing code from the previous lesson.
  • Students should aim to have the project mostly finished by the end of class.

Materials Needed

  • Notebooks
  • Computers
  • Basebots
  • VEXcode IQ

Lesson Procedure

1. Overview

  • Students will continue coding the full project, starting from where they left off in the previous lesson.

2. Getting Started

  • Teachers should check in with each group and ask what still needs to be done before testing next class.
  • Students should write down what needs to be done in their notebooks so they have a clear plan for the work day.

3. Monitoring Progress

  • Students should first tackle the problems they wrote down in the previous lesson.
  • Teachers may help groups troubleshoot if they have trouble finding an issue.
  • After that, students should work on anything they have not coded or tested yet.
  • Students should continue tracking which pseudocode steps have been completed in code.
  • The goal after this lesson is to have all major robot functions done and tested.

4. Wrapping Up

  • Each group should summarize what they completed and how confident they are for the test next class.
  • Discuss as a class what challenges students encountered during implementation and how they solved them.

Assessment

  • Students should have a functional version of their bot by the end of class.
  • A little time will be given next class for final touch-ups, but all major work should be complete.
  • Student notebooks should include notes on test results, current bugs, and potential bugs.

Preparation for next class

Students should be prepared to test their bots next class.
