Programming Definitions (Lesson 2.1)

Programming

The process of giving a computer a set of specific, step-by-step instructions to perform a task or solve a problem. Coding is another word for programming.

Code

The actual instructions given to a computer.

  • Code is written in a specialized programming language that the computer can understand.

Some real-life objects that use programming

  • Parts of cars
  • Smartphones
  • Calculators
  • And many more!

Programming Process

The process used to program a computer to do a specific task.

  • Have a clear idea of what you want the program to do.
  • Step 1: Identify the problem or task — what does the robot need to accomplish?
  • Step 2: Describe a series of actions that solves the problem (can be done using pseudocode, taught later).
  • Step 3: Write your program — choose a programming language and describe what you want the computer to do.
  • Step 4: Test and improve — debugging means finding and fixing errors (“bugs”).
  • Sometimes you’ll need to return to Step 2 to refine your actions.
