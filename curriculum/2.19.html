Lesson 19: Work day

Lesson Objectives

  • In this lesson, students will take their pseudocode and convert it into working code on the VEXcode IQ website.

Materials Needed

  • Computers (1 per group)
  • Basebots
  • VEXcode IQ website
  • A randomly generated maze (created with white tape), preferably on a dark surface in order to make it easier to code the sensors. There should be colored tape (blue/red/green) marking the end of the maze.
  • Notebooks with pseudocode from the previous lesson

Lesson Procedure

1. Overview

  • In this lesson, students will take their pseudocode and convert it into working code on the VEXcode IQ website.
  • They will test and change it until it works.

2. Getting Started

  • Class discussion: see where everyone is so far.
    • Ask if anyone needs help with anything.
  • Review the goal for the day. Students should have at least one of their functions converted and working in preparation for the final test day.

3. Monitoring Progress

  • Students should convert one function at a time:
    • Color sensing function
    • Movement with a color-sensing function (move while seeing the color)
  • If they run into problems, suggest using print statements to display what is happening on the brain screen.
  • If they are still struggling, the instructors should help them.

4. Wrapping Up

  • Students should make sure they have at least one working function in preparation for the final test.

5. Assessment

  • Ask students to write in their notebooks what went well and where they struggled.
  • Discussion:
    • How can color sensing be used in the real world?
    • How did your real code differ from the pseudocode from previous classes?
    • Are you satisfied with where you are in your code?

Preparation for next class

Students should be prepared to finish their functions for the final test. Students should review their notebooks to make sure they know all of the syntax.
