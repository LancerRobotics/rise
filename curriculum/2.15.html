Lesson 15: Work Day

Lesson Objectives

  • Begin actually coding for the game
  • Test and refine, if time allows

Materials Needed

  • Pseudocode from last class
  • Computers for coding
  • Path layout on the ground

Lesson Procedure

1. Overview

  • In this lesson, students will turn their pseudocode and auton plan into code
  • They will test and change it until it works

2. Getting Started

  • Class discussion about each group’s plan
    • Have each group come up and give their ideas for the project
    • Discuss the pros and cons of each plan
  • Students will begin their code on the website
    • They should test on the field frequently to ensure things running properly

3. Monitoring Progress

  • Help students with coding difficulties, but do not do it for them
    • Allow them to problem-solve through trial and error
  • Everyone works at a different pace, so it is ok if one group is still working on pseudocode while another group is already testing.

4. Wrapping Up

  • Put away the computers and robots
  • Have each group share where they are at and approximately how much time they will need next class.

5. Assessment

  • Students are mostly finished with their code and are ready to test the next class.

Preparation for next class

The next class will give students a little time in the beginning to finish their projects, and then each group will test.
