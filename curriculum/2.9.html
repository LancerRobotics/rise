Lesson 9: Dance Routine Project

Objective(s)

  • Create a dance routine for the robot to showcase your coding skills so far

Materials Needed

  • Notebooks and writing utensils for each student
  • Computers (ideally 1 per group)
  • Basebots
  • VEXcode IQ website

Lesson Procedure

1. Overview

  • In this lesson, students will combine their knowledge of loops, movement, sensors, conditional statements, and timing to create a dance routine for their robot. They can also explore various other blocks that could be fun to include in their project.

2. Getting Started

  • Go to the VEXcode IQ website and ensure that all motors and sensors are set up in the devices section.
  • Use this document to learn what each section on the website is
  • Students should write down the basics of what each section is, but do not need to write down every single block’s function.

3. Monitoring Progress

  • Have students write down in their notebooks the pseudocode for the dance routine.
  • When they are done writing the pseudocode, students can code their dance routine for the rest of the class and encourage them to be creative!

4. Wrapping Up

  • Have every group show off their robot’s dance routine
  • Vote on which group’s dance routine they thought was the best and offer them a small prize for encouragement

Assessment

  • Students understand the functions of each section on the VEX IQ code website
  • Students are able to convert pseudocode to code
  • Students can code a creative dance routine

Preparation for next class

In the next class, students will learn how to use variables in order to make their routine even more varied!
