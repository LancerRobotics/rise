Lesson 26: Work Day

Objective(s)

  • Students will begin coding the full program based on completed pseudocode from last class.
  • Students will test and debug code to ensure functionality.

Materials Needed

  • Notebooks
  • Computers
  • Basebots
  • VEXcode IQ

Lesson Procedure

1. Overview

  • Students will begin coding the full project using the pseudocode created in the previous lesson.
  • Students will test their code and use debugging strategies from earlier lessons to improve it.

2. Getting Started

  • Students should review their pseudocode and confirm that all steps are clear before beginning to code.
  • Groups should decide which MyBlock or full-program section to code first.

3. Monitoring Progress

  • Have student groups test and document what works and what needs adjustment in their notebooks.
  • Students should identify potential problems, even if they do not have time to fix every issue during class.
  • Teachers should guide debugging strategies and testing when students ask for help.
  • Students should track coding progress in their notebooks by marking which pseudocode steps have been converted into code.

4. Wrapping Up

  • Each group should summarize what they completed and list current or potential problems that still need to be fixed.
  • Discuss as a class what challenges students encountered during implementation and how they solved them.

Assessment

  • Students should have a functional, or at least partially functional, version of their program by the end of class.
  • Student notebooks should include test results, current bugs, and potential bugs.

Preparation for next class

Students should be in a good position to mostly finish the project next lesson.
