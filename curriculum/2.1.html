Lesson 1: What is Programming?

Lesson Objectives

  • Understand programming’s role in robotics
  • Recognize everyday examples of code
  • Outline a simple problem-solving process for code

Lesson Overview

Intro to what programming is and where it appears in daily life.

Connect programming process to the Engineering & Design process.

Materials Needed

  • Notebooks
  • Definitions handout

Getting Started

  • Whole-group discussion: what is programming? where do you see it?
  • How coding can make robots more capable.

Monitoring Progress

  • Students take short notes; quick share-outs to gauge understanding.

Wrapping Up

  • Discussion: similarities to EDP; why debugging matters.

Assessment

  • Explain programming
  • List three code-driven objects
  • Describe a programmer workflow
