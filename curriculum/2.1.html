Lesson 1: What is Programming?

Lesson Objectives

  • Understand the basic concept of programming and its role in robotics
  • Recognize where programming exists in our daily lives
  • Learn the steps programmers follow to solve problems using code

Lesson Overview

The purpose of this lesson is to introduce students to the idea of programming, and how it can be used to make their robots more powerful. In addition, students will gain insight into how programming is used in their everyday lives. Finally, students will learn about the process programmers use to solve a problem, similar to the Engineering and Design process that they’ve learned about previously.

Materials Needed

  • Notebooks for each student
  • Programming Definitions Document

Lesson Procedure

Getting Started

  • Begin with a whole-group discussion about what the students think programming is, and where they’ve seen it in everyday objects. Then discuss how programming can help them build more powerful and advanced robots.
  • Discussion Prompts:
    • What do you think programming/coding is?
    • Do you see any objects that use code in the classroom? In the school?
    • Which objects use code, and which objects are purely mechanical? For example, do you think light bulbs and light switches use code? What about phones? Cars and motorcycles?
    • How do you think coding can help make your robots better?

Monitoring Progress

  • Go through programming definitions with the entire class, introduce definitions of programming, real life examples, and the process which programmers use to accomplish a task
  • While going through the information, students should be taking notes in their notebooks. Make sure all students have enough time to get the important information down, they do not need to copy down every little detail.

Wrapping Up

  • Come back together for a group discussion about the programming process.
  • Discussion Prompts:
    • How is this similar to the Engineering and Design process?
    • Why is knowing how to debug your code important?

Assessment

  • Students can explain what programming is and how it is important
  • Students can name at least three objects that use code in everyday life
  • Students can describe the process that programmers use and the importance of each step.

Preparation for next class

Next class will be much more hands-on. Students will go on the computers and experiment with the website that will be used throughout the entire course. Prepare an open and flat area, as students will run a simple code that makes their robot go forward. If the basebots were disassembled from the end of the previous course, take some time in the beginning of the lesson to reassemble the basebots.
